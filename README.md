# Курсовой проект. БД.

## Описание:
Проект представляет собой приложение, которое получает информацию с платформы HeadHunter.ru.
Сохраняет их в базу данных и позволяет производить операции.

## Логика проекта:

### Проект состоит из модулей:
* hh_api.py - получает информацию с HH.ru
* db_work.py - работа с БД
* utils.py - функции создания БД и определение ее структуры
* main.py - функция для работы с приложением

Также при работе с приложением создается БД Postgres на ПК пользователя.
Необходимо наличие графического клиента PGAdmin
